# Manufacturing Process Planning of a Forged Connecting Rod

## Overview

This project was developed during the Manufacturing Technology course as part of my Mechanical Engineering degree.

The objective was to design the complete manufacturing process plan for a forged connecting rod, including material selection, manufacturing route, machining operations, heat treatment and production planning.

## Project Objectives

- Select the appropriate raw material
- Define the production type
- Plan the manufacturing sequence
- Select manufacturing equipment
- Optimize the production process
